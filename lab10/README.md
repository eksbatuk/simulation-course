### Система массового обслуживания M/M/* с усложнениями

Реализовать систему M/M/* с **двумя дополнительными правилами** (ООП).

**Возможные усложнения:**
- ограничение числа приборов (вероятность отказа);
- очередь;
- нетерпеливость заявок;
- требования к ресурсам (детерминированные или случайные).
- GUI или подробное логирование и вывод результатов работы в отдельный файл

## 1. Описание приложения:

Программа представляет собой приложение для моделирования системы массового обслуживания ($M/M/c/K$ с детерминированным временем ожидания) с ограниченным количеством приборов и нетерпеливостью заявок. Пользователь имеет возможность настройки параметров симуляции.
*   **Интенсивность заявок ($\lambda$)** — средняя частота прихода новых запросов в единицу времени.
*   **Интенсивность обслуживания ($\mu$)** — среднее количество запросов, которое один прибор способен обработать за единицу времени.
*   **Количество приборов ($n$)** — число параллельно работающих каналов обслуживания.
*   **Мест в очереди ($K$)** — максимальная вместимость буфера ожидания.
*   **Макс. время ожидания** — фиксированное время, по истечении которого заявка покидает очередь, если не была принята на обслуживание.

## 3. Вывод

В ходе лабораторной работы была успешно реализована объектно-ориентированная имитационная модель СМО $M/M/n/K$ с поддержкой динамического отслеживания нетерпеливости заявок.Экспериментально подтверждено действие эргодического свойства марковских процессов: при увеличении времени моделирования (времени наблюдения за системой) средние по времени показатели (доли времени нахождения прибора в состояниях 0 и 1) устремляются к их стационарным теоретическим вероятностям. Для получения качественных и достоверных результатов при анализе СМО симуляции необходимо запускать на длительных временных интервалах ($T_{sim} \ge 1000$), чтобы минимизировать влияние переходных процессов начального состояния системы.
