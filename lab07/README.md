### Марковская модель погоды

**Задание:**  
Смоделировать погоду по дням:

- 1 — ясно  
- 2 — облачно  
- 3 — пасмурно  

Единица времени — **1 день**.  
Задать интенсивности переходов между состояниями.

**Требования:**
1. Выполнить моделирование в «реальном» времени с визуализацией.
2. Провести статистическую обработку результатов.
3. Сравнить эмпирическое распределение с теоретическим стационарным.
4. Сбор статистики и всей необходимой информации в .txt или .csv формат (.csv формат предпочтительней)

## 1. Описание программы
Программа представляет собой приложение с графическим интерфейсом, которое с помощью матрицы переходов может моделировать погоду на основе теории цепей Маркова. Пользователь может изменять матрицу переходов, скорость моделирования и экспортировать логи в .csv файл.

## 2. Математическая основа
Программа работает на основе матрицы переходов P, где q[i][j] - вероятность перехода из состояния i в состояние j. Поскольку в матрице содержатся вероятности, то каждый элемент матрицы обязан находиться в области [0;1], а сумма элементов каждой строки должна быть равна 1.

С каждым шагом во времени генерируется случайное число, равномерно распределённое на интервале [0;1], а затем сравнивается с вероятностями событий переходов через кумулятивный метод.

Вектор стационарных вероятностей $\pi = (\pi_1, \pi_2, \pi_3)$ показывает предельные теоретические вероятности нахождения системы в каждом из состояний при $t \to \infty$. Он удовлетворяет системе уравнений:

$$\pi P = \pi \quad \text{и} \quad \sum_{i=1}^{3} \pi_i = 1$$

Так как уравнений больше, чем неизвестных (одно из трех уравнений баланса является линейно зависимым), мы заменяем последнее уравнение на условие нормировки $\pi_3 = 1 - \pi_1 - \pi_2$.

Подставим $\pi_3$ в первые два уравнения:

$\pi_1(p_{11} - 1) + \pi_2 p_{21} + (1 - \pi_1 - \pi_2) p_{31} = 0 \implies \pi_1(p_{11} - p_{31} - 1) + \pi_2(p_{21} - p_{31}) = -p_{31}$

$\pi_1 p_{12} + \pi_2 (p_{22} - 1) + (1 - \pi_1 - \pi_2) p_{32} = 0 \implies \pi_1(p_{12} - p_{32}) + \pi_2(p_{22} - p_{32} - 1) = -p_{32}$

Мы получили классическую систему линейных уравнений $2 \times 2$:

$$\begin{cases}
a \pi_1 + b \pi_2 = e \
c \pi_1 + d \pi_2 = f
\end{cases}$$

Решаем данную систему методом Крамера. Находим главный определитель матрицы:


$$\text{det} = a \cdot d - b \cdot c$$

Если $\text{det} \ne 0$, единственное решение выражается через вспомогательные определители:


$$\pi_1 = \frac{e \cdot d - b \cdot f}{\text{det}}$$

$$\pi_2 = \frac{a \cdot f - e \cdot c}{\text{det}}$$

$$\pi_3 = 1 - \pi_1 - \pi_2$$
